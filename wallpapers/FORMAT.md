# 映幕桌布包

適用映幕0.36以上。在「桌布與配樂 → 桌布庫」可匯入或匯出`*.yingmu.zip`，新增桌布不用重新下載整套程式。一般使用者直接用程式匯出即可，不必手動編寫JSON。

桌布包是ZIP，最外層放`manifest.json`、一個圖片或MP4，以及選用的獨立音樂、封面圖片。所有媒體都要列出檔名、位元組大小及SHA-256。只接受平面檔名，不可包含資料夾或腳本；檔案總量與ZIP均最多512 MiB。

```json
{
  "Schema": 1,
  "Id": "my-scene",
  "Version": "1.0.0",
  "Name": "我的桌布",
  "Description": "畫面與配樂說明，請保留適用的作者及來源資訊。",
  "Wallpaper": "wallpaper.mp4",
  "Music": "music.mp3",
  "Cover": "cover.jpg",
  "Files": [
    { "Name": "wallpaper.mp4", "Bytes": 12345, "Sha256": "請填入64字元SHA256" },
    { "Name": "music.mp3", "Bytes": 12345, "Sha256": "請填入64字元SHA256" },
    { "Name": "cover.jpg", "Bytes": 12345, "Sha256": "請填入64字元SHA256" }
  ]
}
```

以上大小與校驗碼只是格式示意，不能直接當成有效桌布包。沒有配樂或封面時，移除對應的`Music`／`Cover`欄位和`Files`項目。

`Id`由英文小寫、數字、連字號組成，最多64字元；版本使用三段數字。相同ID與版本必須有相同內容，變更內容請增加版本號。影片建議H.264 MP4；圖片支援JPG、JPEG、PNG、BMP，配樂支援MP3、WAV、M4A、WMA，封面支援JPG、JPEG、PNG。

程式下載會核對官方目錄的ZIP大小及SHA-256；本機匯入也會檢查包內媒體大小與SHA-256、拒絕越界路徑、重複檔名、符號連結、未列出檔案與超量解壓。校驗碼只確認檔案一致，不保證素材的著作權或可解碼性。先預覽再套用，只分享你有權使用的素材。

已安裝內容位於使用者資料夾`Wallscape/wallpaper-packs/<Id>/<Version>`，與應用程式更新分開。不同版本保留不同目錄，不自動覆寫正在使用的媒體；移除桌布清單紀錄不會刪除檔案。原本引用的桌布及配樂不會被搬動。

官方目錄只在按「重新整理線上目錄」時讀取；沒有常駐掃描或自動下載。其他人分享的桌布包可以直接匯入，不需要列入官方目錄。目前沒有自動收件、上傳或審核平台。
