# 映幕 0.18.0 — 桌面工作區

桌面整理新增工作區快照，讓工作、研究等分區配置可以保存與切換。最多保存 8 個工作區，包含位置、尺寸、摺疊、鎖定、顯示狀態、引用與映射資料夾。

- 輸入名稱後按「存成新工作區」。選擇清單不會套用，按「切換」並確認後才變更桌面。
- 切換前自動保留目前配置，可從折疊的工作區管理還原。修改分區後需按「更新所選工作區」更新快照。
- 支援重新命名、移除快照。移除快照保留目前分區與原始檔案。
- 同 ID 分區切換時重建桌面盒，並阻止舊資料夾讀取覆蓋新配置。儲存失敗保留原畫面與配置。
- 分區及整體配置備份包含工作區與切換前配置；還原備份後先停用。桌面配置總計上限 8 MiB，超過拒絕保存。工作區不增加閒置輪詢，只監看目前顯示的映射資料夾。

[官網下載](https://shashift.com/apps/yingmu/) · [版本更新與前版下載](https://shashift.com/apps/yingmu/versions.html)

先從系統匣退出舊版，完整解壓縮後開最外層「映幕.exe」，保留 app 資料夾。0.12 起支援程式內更新。可攜版含執行環境，精簡版需 .NET 10 Desktop Runtime x64。

0.17 及更早版本不支援工作區，退回前請先用本版匯出配置備份；舊版儲存可能移除工作區資料。原始媒體與會議需另外保留。切換工作區不變更桌布、音樂、會議、固定及最近清單。

兩款最終 ZIP 各通過 374 項整合回歸、161 項工作台及 21 項語音檢查，去除重疊各為 382 項不同檢查。首頁短時間待機 RAM 約 133.5–154.3 MiB；CPU 全機平均最高 0.026%。為首頁暖機約 1 秒後量測約 5 秒，不含 DWM，未測 GPU，不能代表桌布或語音用量。

全程未使用 Computer Use，未操作使用者應用或錄製麥克風。包含隔離資料、故障注入與應用自行建立的診斷桌面盒，內部渲染與原生放置檢查不等於使用者真實桌面驗收。多螢幕／混合 DPI、登入啟動、真實斷電與真人會議仍待實機確認。仍為未簽章預覽版。
