# 映幕 0.29.0｜分區設定與名稱草稿

為桌面分區改名或調整顯示與鎖定時，在背景保存，成功才更新目前設定。名稱保存失敗留下草稿；切換分區和工作區先處理草稿，帶著草稿退出也有相同保護。原始檔案不搬動、不改名。

- 分區名稱改為背景保存；成功才更新名稱，失敗保留草稿，可直接重試。
- 切換分區、保存或切換工作區，先完成名稱草稿的保存／捨棄決定；保存期間維持原分區選取，避免草稿對錯分區。
- 啟用桌面分區、顯示／隱藏、鎖定與顯示此分區改為背景原子保存，失敗保留原設定。
- 桌面盒右鍵鎖定及收起共用保存保護，寫入失敗恢復原狀；保存時其他功能頁仍可切換。
- 帶著名稱草稿退出時，保存成功才關閉；失敗保留視窗及草稿，須重試或明確捨棄後再退出。

兩款最終 ZIP 各通過 1027 項整合、787 項工作台及21項語音檢查，去除重疊各 1035 項不同檢查；另各完成工作區、引用、位置快取及分區設定保存，另有退出名稱草稿保存的成功及失敗，加上未確認預覽退出，共二十九種退出情境，確認實際關閉與磁碟內容。另有8個標準大型配置量測，每輪兩個連續5秒視窗及保存分段計時。

首頁短時間待機 RAM 約 135.5–137.3 MiB；CPU 全機平均最高 0.026%。量測條件是桌布關閉、未開其他功能頁、未載入語音引擎；CPU／RAM不含DWM，GPU未測。這是短時間單輪量測，不能推論桌布／語音用量或效能提升。刻意延遲寫入測試證明介面可回應，不能當成磁碟速度變快的證據。
