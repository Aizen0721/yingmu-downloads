# 映幕 0.24.0 — 小視窗與自適應版面

主視窗可依可用工作區縮小，窄視窗改用上下排列與頂部分類選單，保留輸入及播放器。

- 一般最小視窗改為 720×440 邏輯像素。啟動時依目前螢幕工作區縮小並調整位置；特殊更小工作區會再降低視窗尺寸。
- 窄／短視窗改為緊湊版面，桌布預覽與設定上下排列；寬度低於 840 時，左側分類改為頂部分類選單，保留快速啟動與更新入口。
- 分區、會議與歷史欄位在窄視窗上下排列，透過捲動到達操作；清單保留有限可視高度，避免一次展開所有項目。調整版面不重建頁面、搜尋、草稿或預覽。
- 修正開著會議歷史退出時重複關閉，以及恢復視窗後仍停在原生最小化狀態的問題。日誌另外檢查未處理例外與真正的正常退出；未錄製麥克風。

先從系統匣退出舊版，完整解壓縮後開最外層「映幕.exe」，保留 app 資料夾。0.12 起可程式內更新。可攜版含執行環境，精簡版需 .NET 10 Desktop Runtime x64。

兩款最終 ZIP 各通過 612 項整合回歸、374 項工作台及 21 項語音檢查，去除重疊各為 620 項不同檢查。另完成 8 個標準大型配置量測及 1 次診斷重測，各有連續兩個 5 秒待機視窗。首頁短時間待機 RAM 約 135.2–153.1 MiB；CPU 全機平均最高 0.052%。這是空白首頁短時間量測，不能代替大型配置用量。

大型量測每個情境僅一輪，提供兩個視窗原始數據，不以單輪差異宣稱效能提升。所有情境均未進行資料夾掃描或屬性探測，未載入語音引擎；CPU 與記憶體不含 DWM，未測 GPU。配置載入時間不是 Windows 登入開機時間。

0.20 及更早版本儲存可能移除顯示別名；0.17 及更早版本不支援工作區。退回前先匯出備份並取消待還原配置。原始媒體與會議需另外保留。
