# 映幕 0.16.0 — 會議歷史與整合工作台

工作台以桌面整理、桌布與配樂、會議逐字稿及設定分類。會議內新增歷史頁，進階工具預設折疊；首次進入才建立功能頁，未使用語音時不載入辨識引擎。

- 歷史會議名稱／日期篩選、明確執行全文搜尋，以及會議內說話者／文字搜尋。
- 修改段落、重新命名及封存；JSON 保存保留上一份備份，外部修改衝突會拒絕覆寫。錄音中的會議僅供查看。
- 匯入映幕逐字稿 JSON，匯出 TXT／SRT／JSON。文字匯入不帶入聲紋或音訊。
- 有保留 WAV 的會議可回放、調整音量及從所選段落播放。離開頁面停止回放。
- 錄音每 15 秒保存已完成的逐字稿段落，停止後保存；並非完整音訊即時備份。

[官網下載](https://shashift.com/apps/yingmu/) · [版本紀錄與前版下載](https://shashift.com/apps/yingmu/versions.html)

完整解壓縮，先從系統匣退出舊版，再開最外層「映幕.exe」，保留 app 資料夾。0.12 起可用程式內更新。可攜版含執行環境；精簡版需 .NET 10 Desktop Runtime x64。

兩款最終 ZIP 各通過 315 項整合回歸、102 項獨立工作台檢查、21 項語音專項檢查，去除重疊各為 323 項不同檢查。首頁短時間待機 RAM 約 133.3–133.5 MiB；CPU 全機平均最高 0.013%。為首頁短時間待機，不含 DWM，未測 GPU，不能代表桌布或語音用量。

全程未使用 Computer Use，沒有錄製使用者麥克風；錄音回放使用靜音合成 WAV。內部渲染與合成測試不等於真人會議驗收。多人重疊、台灣口音、長會議、多螢幕／混合 DPI 與登入啟動仍待實機確認。仍為未簽章預覽版。
