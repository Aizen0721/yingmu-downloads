# 映幕 0.23.1 — 桌布庫與切換保護修正版

0.23.1 修正確認下一張位置時仍能從其他入口重複套用的競爭，並恢復結束後的按鈕狀態。沿用 0.23 的桌布庫篩選、排序、路徑／配樂搜尋及僅收藏輪播。

- 七種清單篩選：全部、收藏、圖片、影片、已配樂、未配樂及播放失敗紀錄；四種排序：收藏優先、最近加入、名稱遞增及遞減。
- 搜尋可比對顯示名稱、原始路徑與配樂位置，多個關鍵字可跨欄位比對。篩選與排序保存至設定與備份，搜尋文字不保存；清除篩選保留排序。
- 設定的進階選項可只輪播收藏，下一張亦使用此來源；至少兩款符合來源的桌布。清單篩選和排序不改變輪播來源，循序輪播依匯入順序。
- 切換在背景只確認需要的位置，可略過離線或無法確認的項目；確認位置時可取消，切頁與停止也會取消未完成切換。未增加開機掃描或常駐索引。

兩款最終 ZIP 各通過 575 項整合回歸、337 項工作台及 21 項語音檢查，去除重疊各為 583 項不同檢查。另完成 8 個大型配置量測程序，各有連續兩個 5 秒待機視窗。首頁短時間待機 RAM 約 134.7–134.8 MiB；CPU 全機平均最高 0.026%。這是空白首頁短時間量測，不能代替大型配置用量。

大型量測每個情境僅一輪，提供兩個視窗原始數據，不以單輪差異宣稱效能提升。所有情境均未進行資料夾掃描或屬性探測，未載入語音引擎；CPU 與記憶體不含 DWM，未測 GPU。配置載入時間不是 Windows 登入開機時間。
