# 映幕 0.17.0 — 整體配置備份與還原

設定頁新增「配置備份與還原」，預設折疊，可一次備份桌面分區、偏好、桌布與配樂路徑、固定項目及快捷鍵。最近使用清單需勾選才包含。

- 選擇備份後先預覽項目數、快捷鍵及偏好差異，再安排下次啟動還原；可在設定頁取消。
- 從系統匣或設定頁「退出映幕」後再開啟；關閉到系統匣不算重新啟動。
- 三份配置作為同一次交易寫入，還原前保留原始配置。失敗或中斷時回復；檔案仍被鎖定則保留日誌並停止啟動，下次再嘗試復原。
- 可安排還原上次配置。還原後桌布與分區先停用，確認位置後自行啟用。Windows 開機啟動狀態不變。
- 備份包含本機路徑，分享前請確認。原始檔案、媒體、模型、聲紋與會議資料需另外保留。僅備份已儲存設定，本頁未儲存修改不匯出。
