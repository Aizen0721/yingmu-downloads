# 映幕 0.14.0 — 整合工作台預覽版

桌布、分區與會議功能原先分散於不同視窗，現在整合成工作台首頁與左側分類，在同一視窗切換。首頁保留三個常用入口，較少用的設定預設折疊。

- 分類：首頁、桌面整理、桌布與配樂、會議逐字稿、設定。
- 折疊項目：分區備份／匯入、引用修復、螢幕及顯示方式、本機語音模型、指定程式規則及輪播。
- 切換頁面保留分區搜尋與會議狀態；按「結束本場」清除本場身份，退出時完成保存。離開桌布頁停止預覽。
- 功能頁首次開啟才建立介面，語音引擎只在登記或辨識時載入。本機模式不會上傳錄音。

## 測試與限制

兩款最終套件各通過 239 項整合回歸與 21 項語音專項檢查（13 項重疊，共 247 項不同檢查）。首頁待機 RAM 約 132.7–133.3 MiB；CPU 全機平均最高 0.013%。這是首頁、桌布關閉的短時間量測；未測 GPU，不能代表語音或播放桌布的用量。

語音仍使用 sherpa-onnx 本機模型，首次另下載約 160 MiB，未接入 Whisper／雲端模型。真實麥克風、台灣口音、多人重疊與長會議待實錄驗收；桌面拖放、混合 DPI 與登入啟動仍待實機確認。未使用 Computer Use。仍為未簽章預覽版本。
