# 映幕 0.28.0｜位置修復背景保存

檔案移動後可更新引用位置，也能更換映射資料夾。位置與清單都在背景保存，成功才更新畫面，失敗保留原設定；資料夾內容掃描另行進行。原始檔案不搬動、不改名。

- 更新檔案與資料夾引用位置，改為背景準備、編碼及原子保存；成功後才更新路徑、類型與顯示別名。
- 更換映射來源先保存新位置，再於背景重新整理清單；不必等待可選的資料夾掃描才完成位置變更。
- 資料夾清單快取也使用背景保存，寫入失敗保留上次清單，不把未保存的結果提前顯示。
- 保存期間暫停分區編輯與更新安裝，其他功能頁仍可使用；重複要求拒絕，工作區切換後拒絕舊位置檢查結果。
- 補上位置修復、映射來源與資料夾快取保存的成功／失敗退出驗證；原始檔案不搬動、不改名。

兩款最終 ZIP 各通過 892 項整合、652 項工作台及21項語音檢查，去除重疊各 900 項不同檢查；另各完成工作區、排序、別名、新增、類型、位置修復、映射來源與快取保存的成功及失敗，加上未確認預覽退出，共十七種退出情境，確認實際關閉與磁碟內容。另有8個標準大型配置量測，每輪兩個連續5秒視窗及保存分段計時。

首頁短時間待機 RAM 約 135.9–136.0 MiB；CPU 全機平均最高 0.052%。量測條件是桌布關閉、未開其他功能頁、未載入語音引擎；CPU／RAM不含DWM，GPU未測。這是短時間單輪量測，不能推論桌布／語音用量或效能提升。刻意延遲寫入測試證明介面可回應，不能當成磁碟速度變快的證據。

分區名稱與一般分區設定仍有同步保存流程。位置屬性檢查只代表當時狀態，不保證稍後仍可開啟。0.24那次147秒異常原因未確定，原始及重測資料保留；GPU、多螢幕／混合DPI、真實登入及真人會議仍待實機驗收。
