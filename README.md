# 映幕 0.19.0 — 引用位置檢查與名稱草稿保護

桌面整理新增「檢查引用位置」，手動確認目前分區記住的位置。只讀取檔案屬性，不讀取檔案內容、不遞迴掃描；不增加閒置輪詢。

- 區分檔案、資料夾、不存在、無法確認與不支援。無法存取或逾時不等於不存在，也不會自動移除引用。
- 新增引用先保存路徑，再背景確認類型，不再靠副檔名猜測。舊引用可手動檢查修正。
- 每次最多 1000 個位置，約 20 秒後停止新增檢查；單次等待約 2 秒，逾時列為無法確認。可取消或離開檢查。
- 進階工具可分別更新檔案或資料夾位置，映射項目請更新來源資料夾。新增、更新、移除與改名儲存失敗時保留原清單。
- 分區名稱未儲存時，可選先儲存、捨棄或取消。保護涵蓋分區選擇、工作區操作、新增分區、還原與退出；草稿會阻止安裝更新。

先從系統匣退出舊版，完整解壓縮後開最外層「映幕.exe」，保留 app 資料夾。0.12 起支援程式內更新，可攜版含執行環境，精簡版需 .NET 10 Desktop Runtime x64。

兩款最終 ZIP 各通過 410 項整合回歸、197 項工作台及 21 項語音檢查，去除重疊各為 418 項不同檢查。首頁短時間待機 RAM 約 133.4–133.6 MiB；CPU 全機平均最高 0.013%。為首頁暖機約 1 秒後量測約 5 秒，不含 DWM，未測 GPU，不代表檢查位置、桌布或語音辨識用量。

全程未使用 Computer Use，未操作使用者檔案或錄製麥克風。以隔離檔案驗證無副檔名、帶點號資料夾、鎖定、取消、逾時及工作區切換競爭；官網畫面採示意路徑與檢查結果。真實離線裝置、多螢幕／混合 DPI、登入啟動與真人會議仍待實機驗收。

原始媒體與會議需另外保留。0.17 及更早版本不支援工作區，退回前先匯出配置，並取消已安排的還原。仍為未簽章預覽版。
