# 映幕 0.22.0 — 媒體位置檢查與修復

圖片、影片或配樂搬過位置後，可從「桌布與配樂 → 媒體管理 → 檢查與修復位置」重新指定來源。

- 手動檢查已記住的桌布與配樂，只讀位置屬性，不讀內容、不掃描資料夾。共享配樂只檢查一次，最多 400 個位置，約 20 秒後停止新增檢查；可取消。
- 區分檔案存在、資料夾、上次不存在、無法確認及不支援。位置存在不代表能解碼；逾時、離線及無權限不自動移除。
- 分別更新影像與這款桌布的配樂，保留顯示名稱、收藏、音量及循環。桌布修復後需重新預覽並套用；配樂會同步目前播放器，不修改其他桌布的共用音樂設定。
- 保存成功才更新播放；失敗保留原設定與播放器。重複桌布位置會合併，優先保留目的項目既有配樂。原始媒體保留，不增加開機掃描或待機輪詢。

先從系統匣退出舊版，完整解壓縮後開最外層「映幕.exe」，保留 app 資料夾。0.12 起可程式內更新。可攜版含執行環境，精簡版需 .NET 10 Desktop Runtime x64。

兩款最終 ZIP 各通過 518 項整合回歸、298 項工作台及 21 項語音檢查，去除重疊各為 526 項不同檢查。另完成 8 個大型配置量測程序，各有連續兩個 5 秒待機視窗。首頁短時間待機 RAM 約 133.9–133.9 MiB；CPU 全機平均最高 0.052%。這是空白首頁短時間量測，不能代替大型配置用量。

大型量測每個情境僅一輪，提供兩個視窗原始數據，不以單輪差異宣稱效能提升。所有情境均未進行資料夾掃描或屬性探測，未載入語音引擎；CPU 與記憶體不含 DWM，未測 GPU。配置載入時間不是 Windows 登入開機時間。

0.20 及更早版本儲存可能移除顯示別名；0.17 及更早版本不支援工作區。退回前先匯出備份並取消待還原配置。原始媒體與會議需另外保留。
