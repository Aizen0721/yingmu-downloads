# 映幕 0.21.0 — 主介面整合、分區別名與鍵盤操作

主介面以工作台首頁、桌面整理、桌布與配樂、會議逐字稿、快速啟動及設定分類，同一視窗切換，進階選項預設折疊。

- 分區引用可按 F2 設定顯示別名，原始檔名與路徑保留；手動引用和資料夾映射皆支援。別名納入工作區與備份。
- 搜尋同時比對別名、原名稱與路徑；快速啟動亦能找到各分區別名，不建立全磁碟索引。
- 清單與桌面盒支援 Enter 開啟、F2 改顯示名稱、Delete 移除引用、Ctrl+Z 復原、Alt+上下移動；文字輸入時保留編輯按鍵行為。Ctrl+F 搜尋，Esc 清除。
- 完成兩款最終套件回歸及八個大型配置量測程序；待機不新增輪詢，不預先載入語音引擎。

[官網下載](https://shashift.com/apps/yingmu/) · [版本更新與前版下載](https://shashift.com/apps/yingmu/versions.html) · [完整資源量測](https://shashift.com/apps/yingmu/performance.html)

先從系統匣退出舊版，完整解壓縮後開最外層「映幕.exe」，保留 app 資料夾。0.12 起可程式內更新。可攜版含執行環境，精簡版需 .NET 10 Desktop Runtime x64。

兩款最終 ZIP 各通過 479 項整合回歸、266 項工作台及 21 項語音檢查，去除重疊各為 487 項不同檢查。另完成 8 個大型配置量測程序，各有連續兩個 5 秒待機視窗。首頁短時間待機 RAM 約 133.7–133.7 MiB；CPU 全機平均最高 0.013%。這是空白首頁短時間量測，不能代替大型配置用量。

大型量測每個情境僅一輪，提供兩個視窗原始數據，不以單輪差異宣稱效能提升。所有情境均未進行資料夾掃描或屬性探測，未載入語音引擎；CPU 與記憶體不含 DWM，未測 GPU。配置載入時間不是 Windows 登入開機時間。

0.20 及更早版本儲存可能移除顯示別名；0.17 及更早版本不支援工作區。退回前先匯出備份並取消待還原配置。原始媒體與會議需另外保留。

全程未使用 Computer Use，未操作使用者檔案或錄製麥克風。官網介面使用示意資料；多螢幕／混合 DPI、登入啟動、離線裝置與真人會議仍待實機驗收。仍為未簽章預覽版。
