# 映幕 0.20.0 — 引用排序、移除後復原與大型工作區量測

桌面整理新增本分區排序，可選加入／自訂順序、名稱遞增、名稱遞減與已確認的資料夾優先。進階工具可調整手動引用上下順序，並切回自訂模式；映射項目不能手動移動。

- 每個分區保留一筆上次移除的引用，可從主頁或桌面盒右鍵復原，重新啟動後仍保留。再次移除會取代該分區上一筆紀錄。
- 復原只恢復引用、顯示名稱與原自訂位置，不會恢復已被外部程式刪除的原始檔案。重複位置或已達 500 個引用時拒絕加入，保留復原紀錄。
- 排序與復原資料包含於工作區、分區及整體備份。儲存失敗保留原排序、清單與復原資料。
- 配置複製改為複製資料物件，減少切換時重複序列化；以欄位一致與修改獨立測試驗證。
- 新增八個獨立量測程序：兩款套件各測空白首頁、大型首頁、分區清單與三個診斷桌面盒。大型資料包含 8 工作區、目前 12 分區及 2400 引用，連同快照與切換前配置共 24000 筆引用紀錄；只使用示意路徑，不探測真實檔案。

先從系統匣退出舊版，完整解壓縮後開最外層「映幕.exe」，保留 app 資料夾。0.12 起可程式內更新。可攜版含執行環境，精簡版需 .NET 10 Desktop Runtime x64。

兩款最終 ZIP 各通過 440 項整合回歸、227 項工作台及 21 項語音檢查，去除重疊各為 448 項不同檢查。另完成 8 個大型配置量測程序，各有連續兩個 5 秒待機視窗。首頁短時間待機 RAM 約 133.3–133.6 MiB；CPU 全機平均最高 0.026%。這是空白首頁短時間量測，不能代替大型配置用量。

大型量測每個情境僅一輪，提供兩個視窗原始數據，不以單輪差異宣稱效能提升。所有情境均未進行資料夾掃描或屬性探測，未載入語音引擎；CPU 與記憶體不含 DWM，未測 GPU。配置載入時間不是 Windows 登入開機時間。

0.19 及更早版本儲存可能移除排序偏好與復原紀錄；0.17 及更早版本不支援工作區。退回前先匯出備份並取消待還原配置。原始媒體與會議需另外保留。
