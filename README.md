# 映幕 YINGMU

目前公開預覽版：0.13.0。此儲存庫提供發行檔與更新資訊。

新增「會議逐字稿」：會前登記姓名與約 10 秒聲音，以本機模型產生中文文字與身份候選。不確定或重疊的發言保留待確認，可人工修正，支援 TXT、SRT、JSON 匯出與選擇保留 WAV。

保留資料夾分區、WitchDrawer 映射盒匯入、圖片／影片桌布、每款桌布配樂與程式內更新。語音模型另下載約 160 MiB，使用時才載入。目前使用 sherpa-onnx；Whisper 與雲端辨識尚未接入。

## 驗證與限制

兩款 ZIP 各通過 213 項功能回歸與 21 項語音專項檢查；其中 13 項重疊，合計 221 項不同檢查。語音僅以公開音檔與測試資料驗證，實際麥克風、台灣口音、多人重疊、長會議仍待實錄驗收；不保證文字與身份完全正確。未使用 Computer Use。

仍為未簽章預覽版本；Windows 可能顯示發行者未知。真實桌面拖放、多螢幕／混合 DPI 與冷開機登入仍待實機確認。
