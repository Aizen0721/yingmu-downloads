# 映幕 0.36.0 預覽版｜可擴充桌布庫

新增「桌布與配樂 → 桌布庫」。升級一次後，之後新增桌布只需下載選中的桌布包，不用重新下載整套程式。

- 線上目錄按需更新，桌布包可單獨下載、取消及重新加入；下載核對大小與SHA-256。
- 匯入別人分享的`.yingmu.zip`桌布包，或把自己選中的桌布與配樂匯出分享，原檔留在原處。
- 桌布包保存在使用者資料夾，與程式更新分開；每個版本保留獨立檔案，重複加入保留使用者音量及配樂偏好。
- 「雨夜・歇腳店」提供原畫及省電兩個獨立包，含約12分06秒配樂。長配樂由既有Suno曲目循環編排，不是12分鐘全新作曲；音樂與24秒動畫各自循環。
- 加入後先預覽，再從主畫面套用；目前桌布、設定及四款既有內建桌布保留。

本版仍為未簽章預覽版。原生影片／靜音音樂解碼與有限播放檢查不能代替真人試聽，也不保證所有播放器的音樂接縫完全無間隙。GPU、實際耗電、多小時待機、真實睡眠喚醒及多螢幕／混合DPI仍待實機驗收。
