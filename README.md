# 映幕 0.15.0 — 快速啟動與常用項目

新增快速啟動面板，跨分區查找應用、檔案與資料夾。在映幕內按 Ctrl+K，或使用 Ctrl+Alt+Space 全域快捷鍵；首頁、側邊導覽及系統匣也有入口。全域快捷鍵可在設定關閉，衝突時仍可使用程式內入口。

- 固定最多 200 個常用項目，保留從映幕分區或快速面板開啟的最近 50 項。
- 搜尋名稱、分區或路徑，支援空白分隔多個詞，Enter 開啟、Esc 收起。只搜尋已記住的清單，不建立全硬碟索引，每次最多顯示 100 個結果。
- 進階工具：加入檔案／資料夾、開啟所在位置、複製路徑、手動檢查目前結果、更新固定位置及清除最近清單。
- 失效檢查只探測目前最多 100 個記住的位置，不遞迴掃描、不刪除原檔。修復固定位置不變更分區引用，分區引用仍由桌面整理管理。
- 清除最近清單時同步清除該清單備份的最近紀錄，固定項目保留。不讀取 Windows 系統最近清單。
