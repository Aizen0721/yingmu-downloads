# 映幕 0.25.0｜工作區背景保存

工作區保存遇到慢儲存時，主介面仍可回應並切換其他功能頁。桌面配置在保存期間暫停編輯，成功原子寫入後才提交；失敗保留原配置與備份。

- 新增、更新、命名、移除、切換工作區及還原分區配置，改在背景準備、編碼及原子寫入。
- 保存時暫停桌面配置及桌面盒編輯，其他頁面仍可使用；重複要求不排隊，成功保存後才切換配置。
- 寫入失敗保留原配置與備份；背景屬性結果等保存結束後重新確認，舊工作區結果不覆蓋新配置。
- 退出會等保存成功或失敗後才關閉，避免失敗訊息阻塞退出；保存中暫停更新安裝與排程還原，並增加分段計時與實際版本標籤。

兩款最終 ZIP 各通過 652 項整合、414 項工作台及21項語音檢查，去除重疊各 660 項不同檢查；另各完成交易中退出成功及失敗兩種情境，確認實際關閉與磁碟內容。另有8個標準大型配置量測，每輪兩個連續5秒視窗及保存分段計時。

首頁短時間待機 RAM 約 135.3–136.8 MiB；CPU 全機平均最高 0.013%。量測條件是桌布關閉、未開其他功能頁、未載入語音引擎；CPU／RAM不含DWM，GPU未測。這是短時間單輪量測，不能推論桌布／語音用量或效能提升。刻意延遲寫入測試證明介面可回應，不能當成磁碟速度變快的證據。

本版改善工作區保存的介面回應性；未儲存分區名稱的前置保存、引用排序與別名等其他編輯仍有同步保存。0.24那次147秒異常原因未確定，原始與重測結果保留。GPU、多螢幕／混合DPI、實際登入與真人會議仍待實機驗收。
