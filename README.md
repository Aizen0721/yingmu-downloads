- 桌面原生視窗順序檢查加入循環偵測與256步上限；桌面圖層搜尋同樣加上上限，避免順序變動時無限走訪。

首頁短時間待機 RAM 約 136.0–136.4 MiB；CPU 全機平均最高 0.039%。量測條件是桌布關閉、未開其他功能頁、未載入語音引擎；CPU／RAM不含DWM，GPU未測。這是短時間單輪量測，不能推論桌布／語音用量或效能提升。刻意延遲寫入測試證明介面可回應，不能當成磁碟速度變快的證據。
