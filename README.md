# 映幕 YINGMU

雪伏特 SHASHIFT 的 Windows 影片桌布工具。

[官網介紹與下載](https://shashift.com/apps/yingmu/) · [發行版本](https://github.com/Aizen0721/yingmu-downloads/releases)

本儲存庫僅提供官方測試版的二進位下載與版本說明，未包含應用程式原始碼。

## 0.7.0 免費測試版

- 內含三款日系風景：櫻風・朝富士、暮影・山寺、花岸・晚晴。
- 原畫品質 1080p／24fps，省電品質 720p／15fps，皆為 24 秒、無音軌。
- 支援本機 MP4、系統匣、收藏、搜尋、輪播與自動暫停。
- 可攜版內含 .NET 執行環境；精簡版需安裝 .NET 10 Windows Desktop Runtime x64。

完整解壓縮 ZIP 後，開啟 `Start.cmd`。管理視窗關閉後預設仍在系統匣執行；請從系統匣選「退出映幕」完全退出。

目前為未簽章測試版；Windows 可能顯示發行者未知。已在 Windows 11 單螢幕環境測試，實體多螢幕、混合 DPI 與休眠情境仍待驗收。目前沒有 Workshop、網頁／3D 桌布或視覺編輯器。

每個版本提供 `SHA256SUMS.txt`。請使用官網連結或本儲存庫的 Releases 取得檔案。

背景採用 [The Outlander — Free Japanese Backgrounds](https://the-outlander.itch.io/free-japanese-backgrounds) 的 CC0 素材；作者揭露為 AI 輔助製圖。映幕新增循環鏡頭、花瓣與光點。套件保留素材及執行環境的授權紀錄。
